# Working on this repository

Crafts Council of India website: Next.js 16 (App Router) + Prisma 7 / PostgreSQL CMS with an RBAC
admin panel, migrated from the static site in `_public_html/`. Start with `docs/PROJECT_OVERVIEW.md`
and `docs/ARCHITECTURE.md`.

## Rules

* **`_public_html/` is read-only.** It is the migration's source of truth and the source of legacy
  images/PDFs (hard-linked into `public/` by `npm run assets:sync`). Never edit or delete files in it.
* **Next.js 16 differs from older versions.** Middleware is `src/proxy.ts` (exports `proxy`);
  `params`, `searchParams` and `cookies()` are async. Check `node_modules/next/dist/docs/` before
  using an API you are unsure of.
* **Authorization is server-side.** Every admin page calls a guard from `src/lib/auth/guards.ts`
  (`requirePagePermission` / `requirePermission`); every server action and API route re-checks
  permissions. Hiding a button is never the only control. New permissions go in
  `src/lib/auth/permissions.ts` and must be reflected in `docs/ROLES_AND_PERMISSIONS.md` and
  `docs/security/RBAC_PERMISSION_MATRIX.md` (`npx tsx scripts/docs/rbac-matrix.ts`).
* **Content types are registry-driven.** Add or change admin-editable fields in
  `src/lib/admin/resources.ts` (collections) or `src/lib/content/sections.ts` (page sections); forms,
  validation and sanitisation follow from there. Update `docs/CONTENT_MODEL.md`.
* **All rich text is sanitised** with `src/lib/sanitize.ts` before storage and rendering.
* **Schema changes** need a Prisma migration (`npm run db:migrate:dev -- --name <change>`) and an
  update to `docs/DATABASE_SCHEMA.md`. Never run `prisma migrate reset` or other destructive commands
  against a database you did not create for the purpose.
* **No secrets in the repository or docs.** Configuration comes from environment variables validated
  in `src/lib/env.ts`; document new ones in `docs/ENVIRONMENT_VARIABLES.md` and `.env.example`.
* **URLs are SEO-sensitive.** Changing a public route requires a redirect (`next.config.ts`,
  `src/proxy.ts` or the CMS Redirects table) and an update to `docs/migration/ROUTE_INVENTORY.md`.
* Legacy CSS (`src/styles/legacy/cci.css`) is kept verbatim; page CSS in `src/styles/pages/` is
  generated by `scripts/scope-legacy-css.mjs` — regenerate rather than hand-edit.

## Verify before claiming done

```bash
npm run lint && npm run typecheck
TEST_DATABASE_URL=postgresql://... npm test     # unit + integration (creates/drops its own database)
npm run build
E2E_ADMIN_DATABASE_URL=postgresql://... npm run test:e2e
```

Only report tests as passing after running them; record results in `docs/TESTING.md` and notable
changes in `docs/CHANGELOG.md`.
