# Data Mapping

Deterministic source → destination mapping implemented in `scripts/import-legacy-content/`. Records are keyed by
their legacy identifier, so re-running the import matches instead of duplicating.

## Events — `events.js` (`EVENTS`, collection `CURRENT`) and `events-final.js` (`PAST_EVENTS`, collection `ARCHIVE`)

| Legacy field | `Event` column | Transformation |
|---|---|---|
| `id` | `legacyId`; `slug` | slug = lower-case, non-alphanumerics → `-` (`slugifyId`) |
| `source_link` | `sourceLink` | verbatim (old WordPress URL) |
| `type` | `type` | verbatim (default `event`) |
| `title`, `subtitle`, `venue`, `city`, `address`, `mapLink`, `entryFee`, `ticketPrice`, `ageGroup`, `parking`, `heroGradient`, `heroEmoji`, `tagLabel`, `tagClass` | same names | verbatim |
| `dates` | `dateText` + `startDate`/`endDate` | text verbatim; dates parsed by `src/lib/dates.ts` (116/116 parsed) |
| `time` | `timeText` | verbatim (archive uses "N/A", displayed as in legacy) |
| `contact[]` | `contact text[]` | verbatim |
| `registration` | `registrationUrl` | verbatim (placeholder links flagged) |
| `pdf` | `pdfUrl` | asset path normalised (no leading `./`, URI-decoded) |
| `image`, `gallery[]` | `image`, `gallery text[]` | normalised asset paths; existence checked |
| `status` | `legacyStatus` | verbatim; drives the sidebar card exactly as legacy |
| `description[]`, `eventWriteup[]` | `descriptionHtml`, `writeupHtml` | each entry wrapped in `<p>` (legacy renderer), sanitised, links rewritten |
| `highlights`, `schedule`, `people` | JSON columns | verbatim objects |
| `related[]` | `relatedSlugs` | slugified |
| `shopTiming`, `pricing`, `map`, `payments`, `specialEvent`, `invitePDF` | `extra` JSON | kept, not displayed (legacy never displayed them) |
| array position | `sortOrder` | index |
| — | `status=PUBLISHED`, `publishedAt=import time` | legacy items were all live |

## News — `news.js` (`NEWS`) → `NewsArticle`

Same card fields as events. `description[]` → `bodyHtml`: entries containing block HTML (`div`, `iframe`, `img`,
`a`, `h1–h3`) kept as sanitised HTML, others wrapped in `<p>` (legacy `renderNews` rule). `gallery[]` → JSON
items `{type:"image",src}` or `{type:"youtube",url}`. Legacy ids with capitals map to lower-case slugs; the old
id still resolves (case-insensitive) and redirects.

## Press — `press.js` (`PRESS`) → `PressItem` + `PressGroup`

`galleries[]` → ordered `PressGroup` rows (`media`, `date`→`dateText`, `readOnline`→`readOnlineUrl`,
`images[]`→`items`). PDFs and images keep their order; the detail page treats `.pdf` as tiles.

## Publications — HTML → `Publication`

| Legacy markup | Column |
|---|---|
| page (`books.html`, …) | `kind`, `isArchived` (past-* pages) |
| `.nl-latest` block | `isFeatured=true`; `.nl-latest-title`→`title`, `.nl-cover-title`→`cardTitleHtml`, cover `.nl-latest-date`→`cardSubtitle`, info `.nl-latest-date`→`dateLabel`, `.nl-latest-desc`→`descriptionHtml`, action link → `fileUrl` + `actionLabel` |
| `.nl-card` | `.nl-card-title` (inline HTML) → `cardTitleHtml` (+ text → `title`), `.nl-card-date` → `cardSubtitle`/`dateLabel`, `.nl-card-cover-logo`/`-headline` → `coverLogoHtml`/`coverHeadline`, cover `style` → `coverBackground`, `img` → `coverImage`/`coverAlt`, read/download presence → `showRead`/`showDownload`, enclosing `.newsletter-year h2` → `groupLabel` |
| `href="#"` | empty `fileUrl`, links hidden (reported) |
| key | `legacyKey = <file>#latest` or `<file>#card-<n>` |

## Awards — `awards.html`, `past-awards.html`

`.awardee-card` → `AwardRecipient` (`isFeatured`, `year` from the section title "2024 - 2025", `award`, `name`,
`craft`, `photo`). Table rows → `AwardRecipient` (`year`, `name`, `award` (AWARD & CRAFT column), `state`,
`listing`). Continuation rows (no name/state, text continuing the previous award) are merged into the previous
recipient; rows without a name are kept as displayed. `.category-card` → `AwardCategory`.

## People & places

* `index.html` `.a-card` → `Artisan` (dedupe by photo: the 4 loop duplicates are dropped and regenerated by the component).
* `about.html` `.tc-list li` → `TeamMember` (`EC_MEMBER` / `OFFICE_BEARER`, `.tc-role` → `role`).
* `contact.html` visible `.affiliate-card` → `StateCouncil` (quick facts by label, contact rows split on `<br>`).

## Crafts

* `craft-data.json` → `CraftState` + `CraftLocation`: state names normalised with the legacy page's own
  `STATE_ID_MAP`/`STATE_ALIAS`; duplicate names merged (original names kept in `sourceNames`); empty craft names
  skipped (as legacy did); empty district → "Unknown" (as legacy did).
* `images/state_images/<folder>/images.json` → `CraftState.mapImage` + `CraftStateImage`.
* `craft-processes.html` `PROCESSES` → `CraftProcess` verbatim (scraped artefacts flagged, not edited).

## Pages, menus, settings

* Page markup → `Page.sections` (`map-pages.ts`), one section per visual block; texts read from HTML;
  links rewritten (`about.html#team` → `/about#team`, `docs/x.pdf` → `/docs/x.pdf`).
* `nav.js` desktop template → `MenuItem` (`main`); `footer.js` arrays → `footer-quick`, `footer-resources`,
  `footer-connect`; legal links → `legal`.
* `footer.js` / `contact.html` constants → `SiteSetting` defaults, verified against the source by the importer.
* All files under `images/` and `docs/` → `Media` (`LEGACY`, size, SHA-1, dimensions).
